# alone: SQLite FTS5 for the index, no network, no wheels to install. This file
# is kept because the submission layout asks for one (docs/submission_rules.md).
#
# It previously pinned numpy / onnxruntime / tokenizers for an optional dense
# sentence-embedding signal. That signal was measured on branches dense_rerank
# and state-encoder-eval, never cleared the noise floor, and has been removed
# along with src/embed.py and tools/build_embeddings.py - see
# docs/team/dense_rerank.md, docs/team/dense_route.md and
# docs/team/branch_state_encoder_eval_changes.md.
#
# The optional DeepSeek reranking layer (src/llm.py) is stdlib-only too - it
# speaks HTTP through urllib and is off unless DEEPSEEK_API_KEY is set
